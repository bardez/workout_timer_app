Política de Privacidade

Workout Timer  ·  Última atualização: 27 de maio de 2026

Esta Política de Privacidade descreve como o aplicativo Workout Timer coleta, usa e protege as informações dos usuários. Ao usar o app, você concorda com os termos aqui descritos.

1. Dados coletados

O Workout Timer não coleta dados pessoais identificáveis diretamente. As informações armazenadas ficam exclusivamente no seu dispositivo:

  • Configurações de treinos criados por você (nome, séries, tempos)
  • Histórico de sessões concluídas (duração, protocolo, data)
  • Preferências do app (plano PRO, configurações de som)

Esses dados são salvos localmente via Shared Preferences e não são transmitidos a nenhum servidor externo.

2. Publicidade Google AdMob

Usuários do plano gratuito visualizam anúncios fornecidos pelo Google AdMob. O Google pode coletar e usar dados do dispositivo para exibir anúncios relevantes, incluindo:

  • Identificadores de publicidade (IDFA / GAID)
  • Endereço IP e dados de localização aproximada
  • Informações de uso e interação com anúncios
  • Dados de diagnóstico e desempenho do dispositivo
O tratamento de dados pelo Google é regido pela Política de Privacidade do Google . Você pode optar por desativar a personalização de anúncios nas configurações do seu dispositivo (iOS: Privacidade → Publicidade; Android: Configurações → Privacidade → Anúncios).

Assinantes do plano PRO (R$ 9,90/mês) não visualizam anúncios e, portanto, não estão sujeitos à coleta de dados pelo AdMob.

3. Permissões do dispositivo

  • Áudio: reprodução de sons de timer (beeps de fase, contagem regressiva). Não grava áudio.
  • Wakelock (manter tela ativa): impede que a tela desligue durante o treino ativo. Desativado automaticamente ao pausar ou encerrar o timer.
  • Armazenamento temporário: geração de screenshot para compartilhamento de estatísticas. A imagem não é salva permanentemente sem ação explícita do usuário.

4. Compartilhamento de conteúdo

O app permite compartilhar um resumo de estatísticas via screenshot. Essa ação é sempre iniciada pelo usuário. O app usa a API nativa do sistema operacional (share_plus) — não envia dados para servidores próprios. O destino do compartilhamento (WhatsApp, Instagram, e-mail etc.) é escolhido pelo usuário.

5. Retenção e exclusão de dados

Todos os dados locais são excluídos ao desinstalar o aplicativo. Não há cópia em servidores externos. Dentro do app, você pode excluir treinos individuais e entradas do histórico manualmente.

6. Crianças

O Workout Timer não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados de menores. Caso identifique uso indevido, entre em contato pelo e-mail abaixo para exclusão das informações.

7. Segurança

Como os dados ficam apenas no dispositivo, a segurança depende das proteções nativas do sistema operacional (iOS Keychain, Android Keystore, criptografia de armazenamento). Recomendamos manter o dispositivo atualizado e protegido com senha ou biometria.

8. Alterações nesta política

Esta política pode ser atualizada periodicamente. Mudanças significativas serão comunicadas por atualização do app com nota de versão. A data de vigência está sempre no topo desta página.
